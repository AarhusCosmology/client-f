.. py:function:: settings_file(directory)

   The run's settings, the one ``*.yaml`` or ``*.yml`` beside its folders.


.. py:function:: iterations(directory, pattern: str) -> dict[int, pathlib.Path]

   {N: path} of the files in ``directory`` named by ``pattern`` with N for its ``*``
   ("model_it_*.keras"). Augmentation arms (e.g. model_it_5_pa2000.keras) are not
   pipeline iterations and are not matched.


.. py:function:: latest_model(run_dir) -> int

   The latest network of a run (trained_models/model_it_N.keras).


.. py:function:: latest_iteration(run_dir: pathlib.Path) -> int

   The latest network or training set on disk, -1 without any: where a continued run
   starts when it is not told (-s).
