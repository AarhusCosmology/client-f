# Configuration fields

Generated from the source at build time. `required` means the parser requires a value. `None` corresponds to YAML `null`; absence of an optional section disables it. Values below are defaults when the field is omitted, not recommended budgets for every problem. See [configuration conventions](../../configuration.md) for activation and validation rules.
