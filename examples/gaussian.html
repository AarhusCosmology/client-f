A small Gaussian: know the answer first#

Consider the objective on \([-5,5]^2\),

\[\ell(x,y)=-\frac12\left[x^2+\frac{(y-0.6x)^2}{0.64}\right]+C.\]

For a fixed \(x\), the nuisance optimum is \(y_*(x)=0.6x\). It remains inside the domain for every allowed \(x\), so

\[2[\ell_{\max}-\ell_{\mathrm{prof}}(x)]=x^2.\]

This gives a check on the meaning of a profile without assuming that any trained network is exact. The Cobaya wrapper adds the normalised uniform-prior constant to the native objective; that constant cancels in the relative profile but matters for evidence.

Execute the exact checks#

python docs/site/examples/analytic_checks.py

The script checks the nuisance optimum, two ridge identities and the equivalence of the two temperature-weight formulas used in the methods chapter. It uses only the Python standard library, runs during documentation CI and makes zero backend calls. It does not train or certify a network.

Run the actual CLiENT smoke example#

Use the first-run command. The short budget is intended to exercise configuration, true evaluation, model saving and sampling. A poor final approximation with this tiny budget is not evidence against the method; increase and validate budgets for an accuracy study.

CLiENT smoke configuration#
# Installation smoke test, not a precision or convergence benchmark.
likelihood:
  wrapper: cobaya
  input: docs/site/examples/gaussian_likelihood.yaml
prior:
  n_samples: 128
  sampling_strategy: lhs
  n_sigma: null
acquisition:
  n_append: 32
  n_neighbors: 10
  pool_factor: 4
  target_temperature: 2.0
model:
  n_layers: 2
  n_neurons: 32
  activation: alsing
training:
  learning_rate: 0.001
  loss: msre
  sigma_level: 3
  n_epochs: 30
  batch_size: 32
  validation_split: 0.2
  patience: 10
sampling:
  sampler: aies
  temperature: 2.0
  n_walkers: 16
  burn_in: 20
  n_steps: 100
  thin: 2
convergence:
  metric: gaussian_posterior_drift
  threshold: 0.01
  max_iterations: 1
seed: 42
Analytic Cobaya target; no CLASS++ or data installation#
likelihood:
  analytic_gaussian:
    external: 'lambda x, y: -0.5 * (x*x + (y-0.6*x)**2 / 0.64)'
params:
  x:
    prior: {min: -5, max: 5}
    ref: {dist: norm, loc: 0, scale: 1}
    proposal: 0.2
  y:
    prior: {min: -5, max: 5}
    ref: {dist: norm, loc: 0, scale: 1}
    proposal: 0.2

After a successful run, profile x using the saved network and compare the true-refined curve with \(x^2\):

python client.py profiles RUN_DIR --params x --points 5 --workers 2 --output PROFILE_DIR

Keep the true unrestricted anchor, node values and finite-call ledger separate from surrogate predictions. This second command needs the scientific environment and is not part of the lightweight documentation build.
