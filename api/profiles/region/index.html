profiles.region#

The profile setting region: a network trained on boosts is searched inside their region.

A run with acquisition.boost.region writes RUN/boost/region_it_N.npz (sampling/region.py): the part of the box the posterior points of its boosts reach. From then on the run’s own chains, audit and evidence see the network only there, and the network is not kept honest anywhere else: it has maxima outside that the truth does not have. A profile is a search for the network’s maximum on a slice of the box, so it finds them. On a real 49-parameter run the optima of the bare network were 40 posterior sigma from the data, 90 to 160 above the true peak in the network and 600 to 700 below it in truth, and no node of the true stage converged; in the region every node of the same study converged in one gradient round (docs/create_profiles.md, “Networks trained on boosts”).

region: run (the default) uses the region as the run saved it, region: E puts its edge at E times the reach of the boost points, region: null is the bare network over the whole box, which is what every study made before the key used. A network of the ordinary loop has no region and is used over the whole box whatever the setting.

A node whose optimum is not inside the region cannot be computed from this network: its slice of the box misses the region, or the network still rises where the region ends. Such nodes are cut from the ends of the parameter’s range, the scan is repeated on the shorter range with the same number of nodes, and the cut is recorded (region in ranges.json, region_cuts in the scan’s file). The study ends only when fewer than two nodes of a parameter are inside.

profiles.region.view_region(run)#

A derived-coordinate view’s record of the region of its source run (view.json region, derived/coordinates.py), or None. Raises ValueError for a view made before views carried the region, from a network that has one: that view is the bare network.

profiles.region.resolve(run, iteration, setting)#

What a study’s results depend on (sampling/targets.py resolve): None for the bare network, or the region’s file, hash and edge. For a view, the region its source run saved, copied into the view, and the pivot map that takes the view’s points to the run’s coordinates.

profiles.region.load(run, entry)#

The region of a manifest’s entry, with the entry’s edge: a Region, or for a view a ViewRegion, which measures the view’s points in the run’s coordinates.

profiles.region.restrict(network, region)#

What the searches see of a network: the network inside region, its wall outside (model.network.restrict_model; for a view, derived.coordinates.restrict_view).

profiles.region.at_edge(region, result)#

What to add to the error of a scan that did not converge: whether the network’s best point inside the region lies at the region’s edge.

profiles.region.shorten(result, flags, grids, names)#

The grids with the nodes outside the region cut from their ends.

Of a parameter’s nodes inside, the consecutive ones around the node nearest the best fit are kept, and the grid becomes as many nodes as before between the first and the last of them. Returns (grids, cuts) with cuts[name] = dict(asked, kept, outside). Raises ValueError for a parameter with fewer than two such nodes.

profiles.region.scan(scan_once, region, grids, names, log=print)#

scan_once(grids) until no node is outside the region, the grids cut in between.

Returns the last result; when anything was cut it carries region_cuts, per parameter the range first asked for, the one kept and every node value found outside. After PASSES scans with nodes still outside it raises RuntimeError.
