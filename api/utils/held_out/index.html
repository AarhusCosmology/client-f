utils.held_out#

The error of a network at points it had not seen.

Every acquisition is evaluated with the true likelihood, and the network that chose the points had not been trained on them. Its predictions there against the true values are a test of that network that costs nothing: at the tempered batch, where the next training set is being built, and at the boost points, where the posterior is.
